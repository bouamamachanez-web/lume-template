LUME - Fashion Website Template

Thank you for purchasing LUME!

INTRUCTIMS ON HOW TO USE IT:
----------------------------

1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server.
4. Replace the images in the images folder with your own.
5. Edit the text inside index.html.
6. Customize the colors and styles in css/styles.css.

FILES
-----

index.html
Main website styling.

css/styles.ss
All website styling.

images/
Images used in the template.

IMPORTANT
---------

This template uses HTML and CSS only.

You can customize the text, colors, images and
other design elements to fit your project.
